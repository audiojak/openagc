# Keyboard shortcuts

Every action in OpenAGC can be reached from the keyboard (spec §14.3). The app shows
this list under **Help › Keyboard Shortcuts** (⇧⌘/). It is generated from
`macos/OpenAGC/App/KeyboardShortcuts.swift`.

## Mail

| Keys | Action |
|---|---|
| `⌘N` | New message |
| `⌘R` | Reply |
| `⇧⌘R` | Reply all |
| `⇧⌘F` | Forward |
| `⌃⌘A` | Archive |
| `⌃⌘I` | Move to Inbox |
| `⌘⌫` | Move to Trash |
| `⇧⌘U` | Mark as read or unread |
| `⇧⌘L` | Star or unstar |
| `⇧⌘I` | Load remote images |
| `⇧⌘N` | Check for new mail |

## Finding mail

| Keys | Action |
|---|---|
| `⌘F` | Search mail |
| `⌘1 – ⌘6` | Inbox, Starred, Sent, Drafts, Archive, Trash |

## In the thread list

| Keys | Action |
|---|---|
| `↑ ↓  or  j k` | Previous or next thread |
| `e` | Archive |
| `#  or  ⌫` | Move to Trash |
| `u` | Mark as read or unread |
| `s` | Star or unstar |
| `l` | Label… |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `c` | New message |
| `/` | Search mail |

## Writing

| Keys | Action |
|---|---|
| `⇧⌘D` | Send |
| `⇧⌘A` | Attach files |
| `⌘B  ⌘I  ⌘U` | Bold, italic, underline |

## Agents and routines

| Keys | Action |
|---|---|
| `⌘K` | Ask the agent |
| `⌥⌘I` | Show or hide the agent panel |
| `⌥⌘R` | Routines |

With Full Keyboard Access on (System Settings › Keyboard), Tab reaches every button,
including approvals in the agent panel.
